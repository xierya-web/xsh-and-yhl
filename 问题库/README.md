# 问题库

每周讨论的问题都放在这里。讨论两人一起进行，讨论完由一人整理后 push，方便随时查看和修改。

## 目录结构

```
问题库/
├── README.md
├── 2026-11_24/                  ← 每次讨论一个文件夹，以讨论日期命名：YYYY-MM_DD
│   ├── Question_discussed.md    ← 本周讨论的问题（Q1、Q2…）
│   └── thought_conclusion.md    ← 每个问题的想法与结论
└── 2026-12_01/
```

## 记录规则

1. 新一周：新建 `YYYY-MM_DD` 文件夹，从上一周复制两个文件，清空内容后再写。
2. 问题编号：同一周内按 Q1、Q2… 编号，两个文件中的编号一一对应。
3. 每次更新：新起一条 `### 日期 时间 · 整理人：xx`（北京时间），往下追加，不删旧记录；修正旧观点就新写一条说明。
4. 同步：写之前先 Pull，写完 Commit 再 Push（GitHub Desktop 或命令行都可以）。
