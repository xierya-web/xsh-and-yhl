# 问题库

我们每周讨论的问题都放在这里。讨论是两人共同进行的，讨论完由一人总结整理后 push 上来，方便随时查看和修改。

## 目录结构

```
问题库/
├── README.md                 ← 本说明
├── 2026-W48/                 ← 每周一个文件夹，命名：年份-W周数
│   ├── 问题A的简短标题/        ← 每个问题一个文件夹
│   │   ├── 问题.md            ← 问题本身：是什么、为什么想讨论
│   │   └── 讨论记录.md         ← 所有想法和讨论总结，按时间往下追加
│   └── 问题B的简短标题/
└── 2026-W49/
```

## 记录规则

1. 每个问题的所有记录都放在这个问题自己的文件夹里（文字、图片、参考链接都可以）。
2. 每次新增或更新想法，都在开头写上日期和时间（北京时间），格式：`### 2026-11-24 14:30`，再写是谁整理的。
3. 新内容往下追加，不要删改之前的记录；想修正旧观点就新写一条，说明改了什么。
4. 写之前先 `git pull`，写完 `git add .` → `git commit -m "W48 某问题 讨论总结"` → `git push`。
5. 周数可以在终端运行 `date +%V`（Mac）查看，或者直接看日历。
